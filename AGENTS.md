# Agent instructions: Vetload native stack

This repository belongs to Vetload's **API session**. It is optional at launch: the API session uses it if and when it needs it.

## Before anything else

1. Read the plan: `../vetload-platform/PLAN.md` locally, or [PLAN.md](https://github.com/Vetload/vetload-platform/blob/main/PLAN.md) for organisation members.
2. Open pull requests; never push to `main`.

## This repository is public

- No secrets, credentials, internal URLs, customer data, pricing, roadmap or strategy. Link to the private platform docs instead of copying them.
- Vetload is standalone. Do not copy code or configuration from any other project on this machine.
- Every check must be able to fail: see new tests fail before they pass, and give every "nothing found" check a positive control.
